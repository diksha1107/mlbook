# mlbook

This repository contains Jupyter notebooks and helper code for practical machine learning examples.

## Repository structure

- `data/` — local datasets and supporting files
- `ml-env/` — project-specific Python virtual environment
- `src/` — main machine learning notebooks
- `tests/` — scratch and experimental notebooks
- `utils/` — helper modules such as plotting utilities
- `README.md` — project overview

## Contents

- `src/CH2_Perceptron.ipynb` — Perceptron learning algorithm
- `src/CH2_Adaline_GD.ipynb` — Adaline with batch gradient descent
- `src/CH2_Adaline_SGD.ipynb` — Adaline with stochastic gradient descent
- `src/CH3_LogisticRegression.ipynb` — Logistic regression
- `src/CH3_SKlearn_basics.ipynb` — Scikit-learn basics and model workflows
- `src/CH3_SVM.ipynb` — Support vector machines
- `src/CH3_DecisionTrees.ipynb` — Decision trees
- `src/CH4_DataPreprocessing.ipynb` — Data preprocessing and scaling
- `src/CH5_DimensionalityReduction.ipynb` — PCA, LDA, and dimensionality reduction techniques
- `src/CH6_FullPipeline.ipynb` — Full workflow with preprocessing, pipelines, cross-validation, and model selection
- `tests/test.ipynb` — experimental notebook for testing and exploration
- `utils/plot_utils.py` — plotting helpers used by notebooks
