# mlbook

This repository contains a collection of Jupyter notebooks for exploring core machine learning concepts through hands-on examples.

## What is in this repository?

- Notebook-based lessons and experiments in [src](src)
- Shared plotting and visualization helpers in [utils](utils)
- A small scratch or experimental notebook in [tests](tests)
- A local Python environment in [ml-env](ml-env) and local data in [data](data)

## Repository structure

```text
mlbook/
├── data/         # local datasets and supporting files
├── ml-env/       # local virtual environment
├── src/          # main machine learning notebooks
├── tests/        # scratch or experimental notebooks
├── utils/        # helper modules
└── README.md     # project overview
```
